# 搭建你的第一个开发环境

欢迎来到视觉组的第一课。在写任何算法之前，你需要先在自己的电脑上搭好开发环境——这一步劝退的人比任何环节都多，所以我们把它放在最前面，手把手带你走一遍。

## 读完这章你能做什么

* 打开 MSYS2 终端，像队内成员一样工作
* 安装好 C/C++ 编译器、CMake、Git 等全套工具链
* 用 VS Code 写代码，并在里面完成编译、运行、调试
* 独立编译一个 C++ hello world，并用 CMake 构建一个小项目

## 我们选哪条路？

搭建 C/C++ 开发环境有很多方式，我们帮你在三条路里选好了一条主线：

```
推荐主线（本章）：MSYS2 + VS Code + CMake（Windows 上接近 Linux 的体验）
        │
        ├── 分支 1：WSL2 / 实体 Ubuntu —— 进阶内容，需要 ROS 2 时再学
        │
        └── 分支 2：Ubuntu 22.04（真机 / Jetson）—— 后面上机器人时才会用到
```

**为什么是 MSYS2？** 它让你在 Windows 上就能获得接近 Linux 的开发体验：用 `pacman` 装包、用 `gcc/g++` 编译、用熟悉的命令行工具工作，而且**不需要装虚拟机、不需要双系统**。视觉组的 C/C++ 入门阶段全部可以在这条主线上完成。

## 本章地图

按顺序读完并动手做完以下四页：

1. [**安装 MSYS2**](install-msys2.md) —— 下载、安装、第一次更新
2. [**安装工具链**](install-toolchain.md) —— GCC、CMake、GDB、Git 一次装齐
3. [**配置 VS Code**](vscode-config.md) —— 编辑器、插件、终端、编译器路径
4. [**验证与排坑**](verify-and-troubleshoot.md) —— 跑通 hello world，对照常见坑自查

四页跟着做完、验证全部通过，你的环境就搭好啦！

## 开始前提醒

* **每一步都要动手做**，不要只看不练。环境搭建出问题，90% 是因为跳步骤。
* 安装路径、命令输出里出现**中文或空格**是很多诡异问题的根源，请全程用英文路径。
* 遇到报错先别慌，“验证与排坑”中整理了新手最高频的坑；解决不了就在群里问，把**完整报错截图**发出来。
