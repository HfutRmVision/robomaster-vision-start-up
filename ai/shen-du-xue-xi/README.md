# 深度学习

## 什么是深度学习？

**深度学习（Deep Learning）** 是机器学习的一个子领域，核心思想是通过**多层神经网络结构自动从数据中学习特征和模式**，尤其擅长处理图像、语音、文本等复杂的非结构化数据。

在 RoboMaster 比赛中，深度学习被广泛应用于目标检测、图像识别、行为预测等视觉任务中，尤其适用于复杂背景下的装甲板识别和能量机关符号识别。

## 深度学习的典型任务

| 任务类型 | 描述 | 应用示例 |
| --- | --- | --- |
| 图像分类 | 判断图像属于哪个类别 | 装甲板类型识别、符号识别 |
| 目标检测 | 找出图像中物体的位置与类别 | 检测多个装甲板或符号 |
| 图像分割 | 像素级标注图像 | 敌方区域分割、装甲板边界提取 |
| 序列预测 | 处理时间序列或空间序列数据 | 敌方轨迹预测、角度/速度估计 |
| 特征提取 | 学习图像中关键特征用于后续分析 | 目标匹配、建图或模型融合 |

## 四种基础深度学习结构

### 1. MLP（多层感知机）

* **结构**：多个全连接层堆叠，每层有激活函数（如 ReLU）
* **适合任务**：结构化输入（如传感器数据、图像的全局特征）
* **局限**：不擅长处理图像等高维数据

### 2. CNN（卷积神经网络）

* **结构**：卷积层 + 池化层 + 全连接层，通过卷积核提取局部特征
* **适合任务**：图像分类、目标检测——视觉组最常用的结构
* **代表模型**：LeNet → AlexNet → VGG → ResNet → EfficientNet

### 3. RNN / LSTM（循环神经网络）

* **结构**：具有循环连接，能处理时序信息
* **适合任务**：时间序列预测、轨迹预测
* **局限**：训练慢，长序列有梯度消失问题

### 4. Transformer

* **结构**：基于自注意力机制，能建模长距离依赖
* **适合任务**：视觉和 NLP 领域都有广泛应用（视觉方向有 ViT、DETR 等模型）
* **在 RM 中**：可用于时间序列预测、目标行为建模等探索性任务，但计算成本较高，目前较少使用

## 深度学习 vs 传统机器学习

| 对比项 | 传统机器学习 | 深度学习 |
| --- | --- | --- |
| 特征提取 | 人工设计 | 自动学习 |
| 数据需求 | 小到中等 | 大量数据 |
| 计算需求 | CPU 即可 | 通常需要 GPU |
| 可解释性 | 较好 | 较差（黑盒） |
| 精度上限 | 中等 | 高（尤其在图像任务上） |

## 推荐学习资源

**书籍**

* 《动手学深度学习》（李沐、阿斯顿张）— **强烈推荐**，提供 PyTorch 版本，理论 + 实战，适合初学者
* 《深度学习》（Ian Goodfellow）— 理论深入，适合进阶

**在线课程**

* **B 站**：搜索 "李沐 深度学习" 或 "动手学深度学习"
* **Coursera**：Deep Learning Specialization（吴恩达）— 系统学习 MLP、CNN、RNN 等基础
* **Fast.ai**：[https://course.fast.ai/](https://course.fast.ai/) — 面向开发者的实战课程，项目驱动

**实战平台**

* **Kaggle**：[https://www.kaggle.com/](https://www.kaggle.com/) — 练习分类、检测等项目
* **Google Colab**：支持免费 GPU，适合训练小模型和做实验
* **Ultralytics YOLO**：[https://github.com/ultralytics/ultralytics](https://github.com/ultralytics/ultralytics) — 支持 YOLOv8/v11/v12，RoboMaster 目标检测首选框架
* **YOLOv5 独立仓库**（旧版）：[https://github.com/ultralytics/yolov5](https://github.com/ultralytics/yolov5)
