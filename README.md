# Welcome!

欢迎加入 RoboMaster 视觉组。

这份手册是你在视觉组的成长地图——从搭建第一个开发环境，到 OpenCV 与相机标定，再到深度学习与模型部署，覆盖了你需要掌握的核心知识。

## 你能从这里学到什么？

* **开发环境**：MSYS2 + VS Code + CMake——零基础也能搭好的第一步
* **编程语言**：C/C++ 为主线（Python 为进阶选学）
* **工程能力**：Git 协作、CMake 构建、ROS 2 通信框架
* **相机与坐标变换**：从像素到世界坐标的完整链路
* **计算机视觉**：传统算法（OpenCV）+ 深度学习（YOLO 等）
* **进阶技术**：Linux/WSL2、ROS 2、SLAM、模型部署

## 学习路线图

```
第零阶段：入门准备（1 周内搞定，卡住立刻问）
├── 关于我们：RoboMaster 比赛简介、视觉组职责
├── 安装 MSYS2
├── 安装工具链（GCC、CMake、GDB、Git）
├── 配置 VS Code
├── 验证：编译 hello world + 用 CMake 构建项目
└── 收藏「公共资源」页：GitHub、OI Wiki 等，遇到问题先去查

第一阶段：C/C++ 与工程能力（4-5 周）
├── C/C++ 入门
├── Git 与 GitHub
└── Makefile 与 CMake

第二阶段：视觉核心（4-5 周）
├── 计算机视觉简介（传统算法）
├── OpenCV 简介
├── 基于深度学习的视觉概述（先留印象，第五阶段展开）
├── 相机基本参数
├── 坐标变换
└── 上下位机通信

第三阶段：目标追踪与状态预测（1-2 周）
└── 目标追踪与预测简介

第四阶段：进阶方向（按需选学）
├── WSL2 / 实体 Ubuntu（Linux 环境分支）
├── ROS 2 机器人操作系统
├── SLAM 与自动导航
├── Python 入门（选学）
└── 强化学习（探索方向）

第五阶段：人工智能（6-8 周）
├── 人工智能概述
├── 机器学习基础
├── 深度学习：Conda 环境管理、CUDA 与 PyTorch、CNN/YOLO
└── 模型量化与部署
```

> 以上时间仅供参考，每个人的基础和学习节奏不同。重要的不是速度，而是每一步都动手实践。

## 怎么用这份手册

1. **按顺序学，别跳着看**——前面章节是后面的基础，跳过容易卡住
2. **零基础先走 MSYS2 主线**——Linux / ROS 2 是第四阶段的进阶内容，不要提前碰
3. **每篇都动手**——看完理论后，一定要自己跑一遍代码
4. **遇到问题先查公共资源页**——GitHub、Stack Overflow、OI Wiki 都是你的朋友
5. **卡住了就问**——群里学长学姐都踩过同样的坑
