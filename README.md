# Welcome!

欢迎加入 RoboMaster 视觉组。

这份手册是你在视觉组的成长地图——从 Linux 基础到深度学习，从相机标定到 SLAM，从 OpenCV 到模型部署，覆盖了你需要掌握的全部核心知识。

## 你能从这里学到什么？

* **计算机基础**：操作系统、网络、数据结构——视觉开发的"隐形地基"
* **编程语言**：Python（快速验证）+ C/C++（高性能落地）
* **工程能力**：Git 协作、CMake 构建、ROS 2 通信框架
* **相机与坐标变换**：从像素到世界坐标的完整链路
* **计算机视觉**：传统算法（OpenCV）+ 深度学习（YOLO 等）
* **进阶技术**：目标追踪、SLAM、模型部署

## 学习路线图

```
第一阶段：打地基（4-6 周，零基础建议多预留时间）
├── 计算机基础知识（操作系统、网络、数据结构）
├── Python 入门
└── Linux 环境搭建

第二阶段：工具链（3-4 周）
├── C/C++ 入门
├── Git 与 GitHub
├── Makefile 与 CMake
└── OpenCV 基础

第三阶段：视觉核心（4-5 周）
├── 相机基本参数与标定
├── 坐标变换
├── 传统视觉算法（颜色分割、形态学、轮廓检测）
└── 上下位机通信

第四阶段：智能感知（6-8 周）
├── 机器学习基础
├── 深度学习（CNN、YOLO）
├── 模型量化与部署
└── 目标追踪与预测

第五阶段：进阶方向（选学，按兴趣深入）
├── SLAM 与自动导航
├── 强化学习
└── ROS 2 系统架构
```

> 以上时间仅供参考，每个人的基础和学习节奏不同。重要的不是速度，而是每一步都动手实践。

## 怎么用这份手册

1. **按顺序学，别跳着看**——前面章节是后面的基础，跳过容易卡住
2. **每篇都动手**——看完理论后，一定要自己跑一遍代码
3. **遇到问题先查公共资源页**——GitHub、Stack Overflow、OI Wiki 都是你的朋友
4. **卡住了就问**——群里学长学姐都踩过同样的坑
