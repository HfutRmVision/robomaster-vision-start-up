# SLAM 简介

SLAM（Simultaneous Localization And Mapping，同步定位与建图）是自动步兵机器人的核心技术——在没有先验地图的赛场中，机器人需要一边构建地图、一边确定自己在地图中的位置，才能实现自主导航。

## 什么是 SLAM？

SLAM 解决的是"我在哪"和"周围长什么样"这两个问题，而且这两个问题互相依赖：

* 要定位，需要知道地图
* 要建图，需要知道自己的位置

SLAM 算法通过同时估计机器人位姿和环境地图，打破了这个鸡生蛋蛋生鸡的循环。

### SLAM 的基本框架

```
传感器数据 → 前端里程计 → 后端优化 → 建图
                ↑                  ↓
              回环检测 ←———————  位姿图
```

* **前端（Frontend）**：从传感器数据中提取运动信息（如相邻帧间的位姿变化）
* **后端（Backend）**：对前端输出的位姿进行全局优化，减小累积误差
* **回环检测（Loop Closure）**：识别机器人是否回到了曾经到过的地方，用于消除累积误差
* **建图（Mapping）**：根据优化后的位姿构建环境地图

## SLAM 的传感器方案

### 激光雷达 SLAM（2D/3D LiDAR）

* **原理**：发射激光束，测量反射时间计算距离，生成点云
* **优点**：精度高、不受光照影响、计算量适中
* **缺点**：激光雷达成本较高，在长廊等几何特征单一的场景容易丢失
* **代表算法**：Cartographer、LOAM、LeGO-LOAM

### 视觉 SLAM（Visual SLAM）

* **原理**：通过相机图像特征点追踪来估计运动
* **优点**：成本低、信息丰富（颜色、纹理）
* **缺点**：对光照敏感、快速运动时容易丢失
* **代表算法**：ORB-SLAM2/3、VINS-Mono（视觉惯性）

### 视觉惯性 SLAM（VI-SLAM）

* **原理**：融合相机和 IMU（惯性测量单元）数据
* **优点**：IMU 提供高频运动估计，弥补相机快速运动时的不足
* **缺点**：需要精确的相机-IMU 联合标定
* **代表算法**：VINS-Mono、VINS-Fusion、ORB-SLAM3

> 在 RoboMaster 中，自动步兵通常使用**视觉惯性 SLAM**（相机 + IMU），因为赛场光照条件复杂、机器人运动剧烈，单视觉方案容易丢失。

## 关键概念

### 特征点与光流

* **特征点法**：在图像中提取角点（如 ORB、SIFT），在后续帧中匹配同名点
* **光流法**：利用像素灰度不变假设，追踪像素在帧间的运动
* 特征点法更准但较慢，光流法更快但容易在纹理稀疏区域失败

### 位姿图优化

前端里程计会产生累积误差——走得越远，误差越大。后端通过构建"位姿图"（节点=位姿，边=相对约束），用最小二乘优化全局位姿。

### 回环检测

当机器人回到起点时，如果检测到"我来过这里"，就可以在位姿图中添加一个约束，把累积误差分摊掉。回环检测通常用词袋模型（Bag of Words）实现。

### 地图表示

| 地图类型 | 描述               | 适用场景   |
| ---- | ---------------- | ------ |
| 栅格地图 | 将空间划分为网格，标记是否可通行 | 导航避障   |
| 点云地图 | 用 3D 点集表示环境      | 三维重建   |
| 拓扑地图 | 用节点和边表示关键位置和连接关系 | 全局路径规划 |

RoboMaster 自动步兵通常使用**栅格地图**做导航避障，结合赛场规则构建半结构化地图。

## RoboMaster 中的应用

### 自动步兵

自动步兵需要在赛场上自主导航，完成巡逻、交战、补给等任务。SLAM 系统负责：

1. **建图**：赛前扫描赛场，构建赛场地图
2. **定位**：比赛中实时确定自己在赛场中的位置
3. **导航**：结合路径规划算法，自主移动到目标位置

### 雷达站

雷达站的定位也依赖 SLAM 技术——雷达需要在赛场地图中定位自己，才能把检测到的敌方位置报告给指挥系统。

## 常用 SLAM 框架

| 框架           | 类型       | 特点                           |
| ------------ | -------- | ---------------------------- |
| Cartographer | 2D/3D 激光 | Google 开源，支持 2D 和 3D 激光 SLAM |
| ORB-SLAM3    | 视觉/视觉惯性  | 支持单目、双目、RGB-D，支持 IMU 融合      |
| VINS-Fusion  | 视觉惯性     | 港科大开源，精度高，适合移动平台             |
| LIO-SAM      | 激光惯性     | 激光 + IMU 融合，室外表现好            |

> 这些框架大多基于 ROS/ROS 2 开发，可以直接作为 ROS 节点运行。
