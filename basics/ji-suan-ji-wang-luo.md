# 计算机网络

## 为什么视觉组要学网络？

在 RoboMaster 中，网络知识主要用于两个场景：

1. **上下位机通信**：视觉数据从上位机传到下位机（可能用以太网 TCP/UDP）
2. **远程开发**：通过 SSH 远程连接机器人上的上位机进行调试

不理解网络基础，遇到通信延迟、丢包、连接失败等问题时会无从下手。

## 核心知识点

### 网络分层模型

* **OSI 七层模型**：物理层 → 数据链路层 → 网络层 → 传输层 → 会话层 → 表示层 → 应用层
* **TCP/IP 四层模型**（实际使用）：网络接口层 → 网络层（IP） → 传输层（TCP/UDP） → 应用层（HTTP 等）

你不需要记住所有层，但必须理解传输层的 TCP 和 UDP 的区别。

### TCP vs UDP

| 对比项 | TCP | UDP |
| --- | --- | --- |
| 连接 | 面向连接（三次握手） | 无连接 |
| 可靠性 | 保证送达，不丢包 | 不保证送达，可能丢包 |
| 顺序 | 保证数据顺序 | 不保证顺序 |
| 速度 | 较慢（有确认重传机制） | 快（无确认机制） |
| 适用场景 | 文件传输、命令控制 | 实时视频流、状态广播 |

在 RoboMaster 中：

* **视觉数据传输**：如果偶尔丢一帧可以接受，用 UDP（低延迟）；如果数据不能丢，用 TCP
* **远程调试**：SSH 基于 TCP

### IP 地址与端口

* **IP 地址**：标识网络中的设备（如 192.168.1.100）
* **端口号**：标识设备上的进程（如 8080）
* 一个网络连接 = 源 IP + 源端口 + 目标 IP + 目标端口

### 常用网络工具

```bash
# 查看本机 IP
ip addr

# 测试网络连通性
ping 192.168.1.1

# 查看端口占用
netstat -tlnp
# 或
ss -tlnp

# 抓包分析（需要 root）
sudo tcpdump -i eth0 port 8080

# 远程登录
ssh username@192.168.1.100

# 远程复制文件
scp file.txt username@192.168.1.100:/home/username/
scp -r folder/ username@192.168.1.100:/home/username/  # 复制目录
```

### SSH 远程开发

在 RoboMaster 开发中，通常你的笔记本通过网线连接机器人上的上位机，然后通过 SSH 远程登录进行开发：

```bash
# 基本登录
ssh vision@192.168.1.100

# 指定端口
ssh -p 2222 vision@192.168.1.100

# 免密登录（生成密钥并推送到远程机器）
ssh-keygen -t rsa
ssh-copy-id vision@192.168.1.100

# 端口转发（把远程的 ROS 2 topic 映射到本地）
ssh -L 9090:localhost:9090 vision@192.168.1.100
```

> VS Code 的 Remote-SSH 插件可以让你直接在远程机器上写代码，体验和本地开发一样。
